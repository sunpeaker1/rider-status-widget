# 라이더짝꿍 위젯 V0.2.0

라이더짝꿍 본체와 완전히 분리된 독립 Android 홈 위젯입니다.

- 패키지: `com.sym.riderstatuswidget`
- 라이더짝꿍 본체 저장소/코드와 분리
- 날씨: Open-Meteo + 현재 위치
- 폰 상태: 배터리 온도, Android 열 상태, 메모리 여유, 기기 부하 추정
- 30분 시스템 갱신 + 앱에서 수동 새로고침
- 상시 서비스 / 접근성 서비스 / WakeLock 없음
- V0.2.0: 초기 시안에 맞춰 글자, 시간, 온도, 날씨, 폰 상태 카드 확대
- Public 저장소의 표준 GitHub Actions로 무료 빌드

빌드: Public 표준 runner 사용.
